# EmaraAI Hub 3.0 - the tools a chat sees

Generated by `scripts/compact_doc.py` from the real servers. Every tool takes `action`; `action="help", topic="<action>"` returns one action's full parameters.
`?` marks an optional parameter. `session_id` is accepted by every action and left out below.

### `batch`

PREFERRED: several calls in ONE request, in order, across team_hub, staff, work, memory. Each step is {tool, action, ...that action's parameters}. A value '$1.field' takes that field from the result of step 1. session_id is given once and added to every step. Stops at the first failing step and says which steps are done.

Several steps in one call, across any of the tools above: `steps=[{tool, action, ...parameters}]`. `$N.field` reuses a value from step N. This is the preferred way to call.
