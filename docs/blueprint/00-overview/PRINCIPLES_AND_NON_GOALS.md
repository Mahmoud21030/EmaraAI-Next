# Engineering Principles and Non-Goals

## Principles

### P1 — Durable State Is Owned by the Platform
Model/chat/browser state is an input, not the source of truth. Tasks, attempts, workspaces, approvals, messages and evidence live in durable platform state.

### P2 — Intelligence and Operations Are Separate
The model proposes/decides/reasons. Deterministic services enforce leases, retries, timeouts, cleanup, permissions, transitions and persistence.

### P3 — Web Chat Is a Provider, Never Infrastructure
ChatGPT/Claude/Gemini browser sessions may be valuable and economical, but the task lifecycle must survive their disappearance.

### P4 — Coding Is Git-Native
Every coding attempt has:
- repository identity,
- base revision,
- workspace identity,
- branch/worktree,
- changed files,
- test evidence,
- resulting commit/diff/artifact.

### P5 — Every Side Effect Is Idempotent or Explicitly Unsafe
Actions must have operation IDs and documented retry semantics. "We probably sent it" is not success.

### P6 — Resource Ownership Is Mandatory
Processes, ports, browser contexts, containers, worktrees, temp dirs, jobs and artifacts are tagged to task/attempt/workspace.

### P7 — Cleanup Is a System Responsibility
Agents can request cleanup, but correctness does not depend on them remembering. Janitor/reaper services enforce cleanup contracts.

### P8 — Unknown Ownership Means Preserve
Never auto-delete a resource if ownership cannot be proven.

### P9 — Evidence Over Claims
Acceptance is based on observed behavior, tests, diffs, screenshots, traces and artifacts.

### P10 — Independent Verification for Material Work
Author and verifier are separate identities and, when possible, separate workspace/runtime contexts.

### P11 — Memory Must Be Selective and Verifiable
More memory is not automatically better. Every durable memory has provenance, scope, confidence and usefulness signals.

### P12 — Model Reputation Is Contextual
No single global "best model". Score model × harness × task type × environment.

### P13 — Simple Core, Replaceable Edges
Provider adapters, UI, runners, storage backends and evaluators should be replaceable without rewriting task semantics.

### P14 — Local First, Distributed Ready
V1 may run on one Windows PC, but ownership, leases and worker contracts must not make future multi-machine support impossible.

### P15 — Fail Closed on Privilege, Fail Visible on Work
Security ambiguity blocks sensitive operations. Execution ambiguity is shown as uncertain/blocked, never silently marked successful.

### P16 — Optimize Time-to-Accepted-Change
Raw model latency/token count is secondary to producing accepted, regression-free work.

### P17 — Observability Is a Product Feature
Every operator-visible action should answer: who, what, why, where, model, workspace, cost, evidence, current state.

### P18 — Feature Parity Must Be Audited
A clean rewrite is not permission to lose mature capabilities.

## Non-Goals

- Reimplement every legacy internal abstraction.
- Keep legacy UI page structure.
- Preserve buggy behavior for compatibility.
- Build a universal cloud platform before local reliability.
- Let the Master micromanage deterministic runtime mechanics.
- Let agents share a mutable coding directory by default.
- Auto-merge high-risk changes without policy.
- Treat memory generated by an agent as truth without validation.
- Route secrets through model prompts unnecessarily.
- Auto-resend uncertain browser actions blindly.
- Use one scalar reputation score as the only routing signal.
- Couple critical workflows to a single vendor.
